## 标题

**组会搭子 · 每周汇报不用再拼记忆**

## 一句话介绍

把「这周干了什么、上次承诺的做完了吗」交给它——一个用 PowerContext 记住你科研进展的小工具。

## 解决的问题

组会前三件事最烦：回忆本周进展、核对上次承诺、拼汇报结构。信息散在聊天记录、代码提交、笔记本里，每次都要花 30–60 分钟重来一遍，还常漏掉上周定下的事。

组会搭子把这件事变成两步：平时一句话记进展，会前点一下出草稿。

## 核心功能

| 功能 | 说明 |
|---|---|
| 记进展 | 一句话记下本轮进展 / 决定 / 卡点，自动归类 |
| 生成汇报 | 按「本周进展 / 上次承诺完成情况 / 卡点 / 下周计划」四段出草稿 |
| 翻旧账 | 直接问"上次说好要做的做完了吗"，它从记忆里把承诺捞出来对照 |

## 技术亮点（这是差异点）

**它记得住，因为记忆不在浏览器里。**
每条记录都写进 PowerContext 的记忆库（带版本、可追溯）。换浏览器、重启服务、甚至换一台机器，只要连同一个 PowerContext，历史都在。

生成汇报时不是把一堆文本丢给模型，而是先取出「上次的决定/承诺」，再和「本周进展」一起喂进去，让模型自己对照——这是它比"聊天记录 + RAG"更准的原因。

技术栈：Qoder 开发 · FastAPI · PowerContext（记忆）· OpenAI 兼容模型 · 单页前端。
